# AutoSkip 使用指南

[返回项目首页](../README.md) · [数据备份与恢复](数据备份与恢复.md) · [识别规则](识别规则.md) · [点击与失败重试逻辑](点击与失败重试逻辑.md) · [故障排查](故障排查.md)

本文介绍 AutoSkip 的安装准备、首次启动、应用范围、规则配置、学习模式和记录管理。AutoSkip 是界面自动化工具：它不会拦截广告请求，只会在广告已经显示、且 Android 能读取相应界面节点时识别并点击“跳过”类控件。

## 使用前准备

### 系统要求

- Android 6.0（API 23）或更高版本。
- 已安装并正在运行的 Shizuku；Root 设备也可使用 Sui 环境。
- 已在 Shizuku 中授予 AutoSkip 权限。

Shizuku 的启动方式取决于 Android 版本和设备状态：Root 设备可直接启动；Android 11 及以上的非 Root 设备通常可使用无线调试；其他情况可连接电脑通过 ADB 启动。具体步骤以 [Shizuku 官方使用指南](https://shizuku.rikka.app/guide/setup/) 和 Shizuku 应用内提示为准。

> [!NOTE]
> 使用无线调试或电脑启动的 Shizuku，通常需要在设备重启后重新启动。AutoSkip 的“开机自动恢复”只能在 Shizuku 已满足运行条件时恢复 AutoSkip 服务，不能代替 Shizuku 自身的启动步骤。

### 下载与安装

1. 从本仓库的 [Releases 页面](https://github.com/ybs15090/AutoSkip/releases) 下载 APK。
2. 在手机上安装或覆盖更新 AutoSkip。
3. 安装并启动 Shizuku，然后返回 AutoSkip 完成首次使用检查。

请只从可信来源下载 APK。Android 通常不允许不同签名的安装包直接覆盖，升级前应确认新旧安装包来源一致。

## 首次使用

首次打开 AutoSkip 后，按照页面顺序完成以下项目：

1. **已安装 Shizuku**：若未安装，点击“安装”并按提示获取 Shizuku。
2. **Shizuku 正在运行**：点击“启动”进入 Shizuku，根据设备情况完成 Root、无线调试或 ADB 启动。
3. **已授予 AutoSkip 权限**：点击“授予 Shizuku 权限”，在授权对话框中允许 AutoSkip。
4. **AutoSkip 服务正在运行**：点击“启动自动跳过”。
5. **开机自动恢复**：按需开启；如果页面提示环境异常，可点击“修复”。

全部完成后，应用进入日常主页。主页会显示服务状态、本次运行时长、最近动作、累计统计和应用范围入口。

## 配置应用范围

进入首页的“应用范围”。应用范围决定 AutoSkip **在哪些应用中执行**，不会改变使用的识别关键词。

| 设置组合 | 实际效果 | 适用场景 |
| --- | --- | --- |
| 关闭“应用范围控制” | 忽略白名单和黑名单，对所有可识别应用生效 | 希望全局启用，并能接受较高误触风险 |
| 开启控制，关闭“严格模式” | 普通模式：默认允许；关闭某个应用即加入黑名单 | 只需排除少数应用 |
| 开启控制，同时开启“严格模式” | 仅对手动开启的应用生效 | 推荐的安全起步方式 |

页面支持按应用名称或包名搜索。每个应用有两个主要入口：

- **应用开关**：允许或禁止 AutoSkip 在该应用内执行动作。
- **识别规则**：配置该应用的专属规则和学习模式。

页面右上角的“黑名单”入口会集中列出所有已加入黑名单的应用。点击某一项的“移除”即可删除其黑名单标记，并可通过底部提示立即撤销。已经卸载但仍保留黑名单记录的应用也会以包名显示，便于清理遗留配置。

从黑名单移除只删除黑名单标记：普通模式下，该应用恢复为默认允许；严格模式下，它仍需要在应用列表中手动开启并加入白名单后才会自动跳过。

向上滑动应用列表时，规则设置卡片、搜索框和模式提示会随列表收起，使列表使用工具栏下方的完整屏幕空间；返回列表顶部并继续向下滑动，可重新展开这些设置。

工具栏中的“回到顶部”位于“黑名单”左侧。无论当前列表滚动到哪里，点击后都会停止惯性滚动、立即回到第一个应用，并重新展开规则设置、搜索框和模式提示。

“单次点击限制”默认关闭。开启后，每次进入一个应用最多自动点击一次；如果同一个前台会话内可能连续出现多个待处理页面，可保持关闭。无论该开关是否开启，启动广告成功跳过后都不会立即启动一轮无意义的主动发现。

## 配置全局规则

在“应用范围”页面点击“全局识别规则”。初始规则包括：

- 控件文字包含“跳过”；
- 控件文字包含“skip”，忽略大小写；
- 控件内容描述包含“跳过”；
- 控件内容描述包含“skip”，忽略大小写。

可以启用、停用、编辑或删除任意规则，也可以点击“恢复默认”重新载入内置规则。

全局规则适合通用文案。若某个关键词也可能出现在普通页面中，应结合精确匹配、区域限制或严格模式降低误触风险。字段和评分说明见[《识别规则》](识别规则.md)。

## 配置应用专属规则

在“应用范围”中找到目标应用，打开“识别规则”：

1. 点击“新增规则”。
2. 选择识别特征和匹配方式。
3. 输入文字、内容描述、View ID、控件类型或正则表达式。
4. 选择控件区域、点击方式和延迟时间。
5. 保存规则，并确认规则开关已开启。

当某个应用存在且启用了专属规则时，该应用使用专属规则替代全局规则。点击“改用全局规则”只会停用并保留专属规则；以后点击“启用专属规则”即可恢复。

## 使用学习模式

按钮文案特殊、倒计时不断变化，或者无法确定 View ID 时，可以采集候选控件：

1. 确认 AutoSkip 服务正在运行。
2. 进入“应用范围”，找到目标应用并打开“识别规则”。
3. 点击“学习模式”→“开始采集”，AutoSkip 会打开目标应用。
4. 在目标应用中进入广告页面，等待真正的跳过按钮出现。
5. 通过最近任务返回 AutoSkip。
6. 在候选列表中选择真正的跳过按钮。
7. 检查自动生成的特征、表达式、区域和点击方式，确认后保存。

候选列表会显示文字、内容描述或 View ID，以及位置、可点击状态和评分。若文字包含变化的数字，例如“5 秒后跳过”，学习模式会尝试将数字部分泛化为正则表达式。

> [!TIP]
> 学习模式生成的是建议规则。保存前应优先选择稳定的 View ID 或明确文字，并把区域缩小到按钮实际出现的位置。

## 查看动作与管理记录

- 首页“最近动作”显示最近一次成功确认的应用、时间和控件文字。
- 发生误触时，可以点击“误触，加入黑名单”，并通过底部提示立即撤销。
- 点击“统计数据”可查看各应用累计次数、首次和最近跳过时间，并按名称、次数、频率或时间排序。
- 在应用记录详情中可以删除单个应用的记录。
- 在统计页面右上角菜单中可以清空全部记录；清空操作无法撤销。

## 更多菜单

首页右上角“更多”菜单提供：

- **可用性测试**：服务运行时验证识别和模拟点击能力。
- **开机自动恢复**：开启或关闭设备启动后的服务恢复。
- **导出日志**：异常时导出日志用于排查。
- **数据备份与恢复**：导出应用范围和全部识别规则，也可选择附带精简统计；导入只提供覆盖恢复。
- **反馈**：通过邮件或 GitHub Issues 报告问题。
- **工作原理**：在应用内查看简要原理。
- **关于**：查看版本、开源许可、捐赠和下载入口。
