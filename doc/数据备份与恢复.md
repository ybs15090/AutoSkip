# AutoSkip 数据备份与恢复

[返回项目首页](../README.md) · [使用指南](使用指南.md) · [隐私与权限](隐私与权限.md)

AutoSkip 可以通过“更多”→“数据备份与恢复”把用户配置保存为 UTF-8 明文 JSON 文件，并在同一设备或新设备上覆盖恢复。文件由 Android 系统文件选择器读写，不需要申请存储权限。

## 导出内容

每次备份固定包含以下内容，不能取消：

- 备份格式、格式版本、导出时间和 AutoSkip 版本等元数据；
- 应用范围总开关、严格模式和单次点击限制；
- 白名单与黑名单中的应用包名；
- 全局识别规则；
- 应用专属识别规则，以及专属规则是否启用。

统计记录是可选项，默认不导出。选中“包含精简统计记录”后，每个应用只保存：

- 包名；
- 跳过次数；
- 首次跳过时间；
- 最近跳过时间。

备份明确不包含运行日志、学习模式临时候选、控件文字、控件坐标、应用名称、图标、已安装应用列表、Shizuku 权限、服务运行状态、首次使用检查结果和开机自动恢复设置。总跳过次数不单独保存；导入统计后由各应用次数重新计算。

## 导出步骤

1. 打开首页右上角“更多”→“数据备份与恢复”。
2. 点击“选择保存位置”。
3. 选择不含统计或包含精简统计；默认是不含统计。
4. 在系统文件选择器中确认文件名和保存位置。

导出不要求停止自动跳过服务。选择包含统计时，服务运行中会读取服务内的最新记录；服务停止时读取本机已经保存的记录。

## 导入步骤

1. 先回到首页，手动停止自动跳过服务，等待状态变为“自动跳过已停止”。
2. 进入“更多”→“数据备份与恢复”，点击“选择备份文件”。
3. 阅读停服提醒后，通过系统文件选择器选中备份。
4. 核对预览中的来源版本、白名单、黑名单、识别规则和统计数量。
5. 点击“覆盖恢复”。成功后返回首页，手动重新启动服务。

程序不会代替用户停止或重新启动服务。它会在打开文件选择器前检查一次，并在真正写入前再次检查；如果服务仍在运行、正在启动或正在连接，导入会被阻止。

## 覆盖规则

- 只支持覆盖恢复，不提供合并模式。
- 应用范围、全局规则和全部应用专属规则会整体替换为备份内容。
- 已经卸载或新设备尚未安装的应用，其包名和专属配置仍会保留。
- 备份包含统计时，本机全部统计会被备份中的精简统计覆盖。
- 备份不含统计时，本机现有统计保持不变。
- 导入不会标记首次使用检查已经完成；新设备仍需正常完成 Shizuku、授权、服务和开机恢复检查。

导入前会完整读取并校验文件格式、字段、枚举值、规则延迟、正则表达式和统计时间。如果写入任一步骤失败，程序会尝试恢复导入前的应用范围、识别规则和统计快照。

## 安全与兼容性

备份文件不加密，能访问文件的人可以看到应用包名和自定义识别规则；若包含统计，还可以看到相应的次数和时间。请只保存到可信位置，分享前先用文本编辑器检查内容。

当前格式标识为 `autoskip-backup`，格式版本为 `1`。程序会拒绝格式不符、字段损坏、超过 4 MB 或版本不受支持的文件，避免把未知结构静默写入现有配置。
