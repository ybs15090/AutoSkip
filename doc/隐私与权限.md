# AutoSkip 隐私与权限

[返回项目首页](../README.md) · [使用指南](使用指南.md) · [故障排查](故障排查.md) · [开发与构建](开发与构建.md)

AutoSkip 需要借助 Shizuku 在特权进程中使用 Android `UiAutomation`，以读取当前界面的无障碍节点并执行点击。本页说明源码当前声明的权限、可以访问的数据、保存在本机的信息和分享日志时应注意的内容。

## 权限概览

当前 `app/src/main/AndroidManifest.xml` 主清单声明两项 Android 权限：

| 权限 | 用途 | 不代表什么 |
| --- | --- | --- |
| `QUERY_ALL_PACKAGES` | 列出已安装应用，用于应用范围、白名单、黑名单和专属规则配置 | 不会读取其他应用的私有文件 |
| `RECEIVE_BOOT_COMPLETED` | 在用户开启“开机自动恢复”后接收设备启动广播 | 不能代替 Shizuku 的启动，也不会绕过 Shizuku 授权 |

应用通过 Shizuku 获得运行自动化服务所需的能力。首次使用时，Shizuku 会显示针对 AutoSkip 的授权请求；拒绝或撤销授权后，AutoSkip 无法启动自动跳过服务。

源码主清单当前没有声明 `INTERNET` 权限。下载更新、打开项目主页、捐赠或发送反馈时，AutoSkip 会把相应链接或意图交给系统中的浏览器、应用商店或邮件应用处理；这些外部应用有各自的权限与隐私政策。

> [!IMPORTANT]
> Shizuku 权限可以让 AutoSkip 启动具备较高能力的服务。请只安装来自可信来源、签名来源明确且可审查的构建，不要安装来历不明的修改版。

## 自动化服务可以看到什么

服务运行期间，`UiAutomation` 可以读取当前活动窗口向 Android 无障碍框架公开的信息，例如：

- 应用包名；
- 控件文字和内容描述；
- View ID、控件类型和窗口 ID；
- 控件位置、尺寸、可见性、可编辑性和可点击状态；
- 窗口与界面内容变化事件。

AutoSkip 使用这些信息匹配用户配置的规则、选择候选并确认点击结果。它不会因为能够读取节点就自动上传节点内容，当前实现也不是网络流量过滤器：不会拦截广告请求、修改目标应用安装包或删除目标应用数据。

Canvas、视频画面、安全窗口以及没有向 Android 暴露节点的 WebView 内容通常无法被按文字读取。相关能力边界见[《点击与失败重试逻辑》](点击与失败重试逻辑.md)。

## 本机保存的数据

以下数据保存在 AutoSkip 的应用私有目录或私有偏好设置中：

- Shizuku 和 AutoSkip 首次设置状态；
- 应用范围开关、严格模式、白名单和黑名单；
- 全局识别规则和应用专属规则；
- 跳过次数、首次时间、最近时间和最近动作；
- 服务运行日志。

应用主清单设置了 `android:allowBackup="false"`，不允许使用常规 Android 备份机制备份应用数据。`android:hasFragileUserData="true"` 会提示系统在卸载场景中把应用数据视为用户可能关心的数据，但是否显示保留提示仍取决于系统实现。

卸载、清除应用数据或在统计页执行不可撤销的清空操作，可能删除这些本地记录。重要专属规则应在操作前自行留存配置或截图。

## 日志导出与分享

“更多”→“导出日志”会通过 Android `FileProvider` 把应用私有日志临时授权给用户选择的接收应用。日志可能包含：

- 手机品牌、型号、Android/API 版本和屏幕参数；
- Shizuku 与 AutoSkip 版本、服务启动时间；
- 目标应用包名和事件时间；
- 命中的控件文字、边界、规则 ID、节点哈希；
- 点击方式、尝试次数和耗时；
- 错误堆栈或运行异常。

日志通常不等同于账号密码，但控件文字、包名和操作时间仍可能泄露使用习惯或页面信息。公开提交 GitHub Issue 前，应先用文本编辑器检查全文，并删除与问题无关的敏感内容。若需要保留上下文，可用一致的占位符替换账号、手机号、订单号或内部应用包名。

## 建议的安全设置

1. 初次使用优先开启严格模式，只允许确有启动广告的应用。
2. 对文案常见的目标使用精确匹配、View ID 或较小区域，避免全局宽泛规则。
3. 不需要自动跳过时停止服务；不需要开机恢复时关闭对应选项。
4. 定期检查应用范围、专属规则和最近动作，发现误触立即停用相关规则或加入黑名单。
5. 只通过可信渠道更新，并在覆盖安装前确认签名来源一致。
6. 分享日志前始终人工检查，不直接公开未经审阅的完整日志。

- 日志共享范围：`app/src/main/res/xml/file_paths.xml`
- 应用范围存储：`app/src/main/java/top/xjunz/automator/rules/AppRulePreferences.kt`
- 识别规则存储：`app/src/main/java/top/xjunz/automator/rules/RecognitionRulePreferences.kt`
- 自动化服务：`automator/src/main/java/top/xjunz/automator/AutomatorConnection.kt`
